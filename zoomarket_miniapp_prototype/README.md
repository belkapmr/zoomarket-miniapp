# ЗооМаркет — Telegram Mini App (UI prototype)

Это стартовый интерфейс мини-приложения для @MarketZOO_bot.

## Что уже есть
- адаптивный интерфейс под Telegram WebApp;
- поиск и категории;
- демонстрационные карточки животных, товаров и услуг;
- форма создания объявления;
- предпросмотр объявления;
- разделы «Мои», «Избранное», «Профиль»;
- подключение Telegram WebApp SDK и получение имени пользователя.

## Важно
Это пока фронтенд-прототип. Объявления сохраняются только в памяти текущей страницы.
Для полноценной работы необходимо подключить:
1. HTTPS-хостинг;
2. сервер/API и постоянную базу данных;
3. загрузку фотографий в облачное хранилище;
4. проверку `Telegram.WebApp.initData` на сервере;
5. Telegram-бота с модерацией и уведомлениями.

Никогда не помещайте токен бота в `index.html` или другой клиентский код.
Токен, ранее отправленный в переписку, нужно отозвать через @BotFather и хранить новый только в серверных переменных окружения.

## Быстрый просмотр
Откройте `public/index.html` в браузере для просмотра интерфейса.
Для запуска внутри Telegram страница должна быть опубликована по HTTPS и привязана к боту через @BotFather (`/setmenubutton` или настройки Main Mini App).
